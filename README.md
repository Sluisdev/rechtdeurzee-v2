# About This Project

Rechtdeurzee is a men's choir that consists of a group of approximately 50 men. Their website's goal is to provide more clarity on who they are, how to contact them, and a place to locate their upcoming events. 

# The Technical Side

The front-end is built with HTML, CSS & JavaScript. The design of the website is almost entirely done by myself. The wave-shaped background for the musicians is made with a CSS shape generator. The carousel with all sponsors is also not entirely my own code. I have taken this from a how-to article. The website is also adjusted for different screen sizes by means of media queries.

As mentioned above, the Rechtdeuzee website also has a backend. This makes it a fullstack project. The backend is built with NodeJS & Express as a framework for routing. As a database I used MongoDB in combination with Mongoose for modeling the data before it is stored in the database. In this project I use EJS as templating engine. For example, the agenda page with the upcoming events is dynamically generated with EJS.


### Features
* Sponsor logos in a carousel
* Responsive UI
* Footer component with upcoming events
* Hamburger menu for smaller screen size
* Login portal (backend)
* Password reset via email
* Fully manageable agenda (CRUD)
